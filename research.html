Project stages

Each stage builds on the one before it.

    Choose a topic, write the research question and list what I need to find out.

  2. Find and read sources

    Collect reliable articles and record notes and references for each one.

  3. Analyse the information

    Compare what the sources say and organise the findings with tables or charts.

  4. Write the report

    Present the findings clearly, then add conclusions and a reference list.
